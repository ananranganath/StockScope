# AI Stock Valuation Platform

## Overview

An AI-powered web application that helps investors estimate a company's intrinsic value using financial valuation models, compare it to the current market price, and generate an AI investor summary based on financial data and recent news.

## Planned Features

- Search publicly traded companies
- Display current stock price
- Calculate intrinsic value using DCF
- Compare intrinsic value to market price
- AI Investor Summary
- Recent company news
- Buy / Hold / Sell recommendation

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Python

- Financial Modeling Prep
